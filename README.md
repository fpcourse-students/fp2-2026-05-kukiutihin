# ФП 2.0. Домашка 5. Интерпретаторы

В главе 5 один язык задаётся деревом синтаксиса, другой — интерфейсом операций. Здесь вы расширите Lalalang функциями и напишете две интерпретации арифметической программы. Домашка сдана, когда обе задачи уровня 1 получили DONE. Задачи уровня 2 предназначены для углубления, уровень 3 — челлендж.

## Установка

Нужны GHC 9.10.3, Cabal, `make` и HLint. GHC и Cabal можно установить через [ghcup](https://www.haskell.org/ghcup/):

```sh
ghcup install ghc 9.10.3 --set
ghcup install cabal recommended --set
```

Версия GHC закреплена в `cabal.project`, зависимости — в `cabal.project.freeze`. На Windows используйте `make` из MSYS2, установленного ghcup (`pacman -S make`). Подсказки HLint помогают улучшить код и не влияют на статусы задач.

## Порядок работы

1. Выполните `make build`. При первой сборке Cabal установит зависимости.
2. Заменяйте `todo "…"` реализацией. `todoImpl` обозначает место полного инстанса: удалите эту строку и самостоятельно напишите `instance ... where` с ограничениями и методами. Если задача расширяет синтаксис или интерфейс, добавьте соответствующие конструкторы, методы и ограничения сигнатур.
3. Запустите `make repl`. После изменений используйте `:r`, для просмотра типа — `:t`. Одноимённые функции различайте по модулю: `Level1.displacement` и `Lalalang.Programs.displacement`.
4. Выполните `make check`: линтер, тесты и таблица статусов. Отдельные задачи: `make check ONLY="2.1 2.2"`. Фильтр оставляет остальные задачи незапущенными; ненулевой код выхода при открытых `1.x` ожидаем.
5. Когда домашка выдана в личный репозиторий, отправляйте текущую версию командой `make submit`. Отчёт CI появится в pull request.

Список проверяемых задач находится в `TASKS`. DONE — все проверки прошли; PARTIAL — прошла часть; FAILED — ни одна не прошла; TODO — проверки упёрлись в заглушки. После реализации можно проверить в GHCi:

```haskell
Level1.expr1 :: Int
Level1.displacement 50 30 2 :: Int
Level1.displacement 50 20 10 :: String
eval (Lalalang.Programs.displacement @ 50 @ 30 @ 2)
eval (fac @ 5)
fac' 5
```
